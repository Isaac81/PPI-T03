# PPI-T03
Trabajo 04 para la UA Programación para Internet
<p align="justify">Se añadió la funcionalidad para guardar las tareas en una base de datos SQLite con las funciones CRUD. Se requiere instalar Node.js para ejecutar este proyecto. Después se debe localizar la carpeta del proyecto en la terminal e ingresa el siguiente comando:</p>

```bash
npm install
```
<p align="justify">Posteriormente se necesita ejecutar el proyecto para lo cual se hace uso del comando siguiente:</p>

```bash
npm start
```

<p align="justify">A partir de este punto se deben seguir los pasos de la Tarea 03. Localice el archivo index.html y haga doble clic sobre él para abrir una ventana en su navegador predeterminado.
Para agregar tareas, escriba un texto en el único lugar posible de la página y haga clic en el botón con el signo +. Las tareas se desplegarán en una lista debajo de la sección de creación. </p>
